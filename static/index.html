第三方 QQ Bot 只读 HTTP 接口

面向 OneBot / Lagrange / NoneBot 等第三方机器人提供只读 HTTP 接口，数据格式向后兼容，字段只增不减。

接口

  • GET /api/v1/bot/random?series=&tag=&animated= 打开

    随机返回一张表情，支持按套系、标签或是否动图过滤；没有匹配结果时仍返回 HTTP 200，响应体为 code=404、data=null。

  • GET /api/v1/bot/search?q=&limit=10 打开

    关键词全文检索（支持中文、拼音、韩文原名、OCR 文本），limit 默认 10、最大 50，offset 翻页；只认这三个参数，多传的 tag、animated、series 会被忽略。空结果仍是 code=0。

  • GET /api/v1/bot/emotes/{id} 打开

    获取单张表情详细元数据与高清直链；id 不存在时返回 404 与 {"detail":"Emote not found"}。WebP 不被客户端支持时，可用 /images/gif/{id}.gif 取同一张的 GIF 版。

  • GET /api/v1/bot/tags 打开

    获取当前库内所有可用标签及表情数量。

  • GET /api/v1/bot/series 打开

    获取全部套系及数量；返回的 id 可直接用作随机接口的 series 参数。

  • GET /data/memes.json 打开

    无需后端服务即可由 CDN / GitHub Pages 直连读取的全量静态元数据快照。

  • GET /e/{id} 打开

    表情详情网页：大图、套系、标签和下载按钮都在这一页，可直接分享。

  • GET /?q=&series=&tag= 打开

    搜索结果网页：关键词、套系、标签都可写进地址，刷新和分享能还原。

说明

是否需要密钥
不需要。接口只读、公开，正常频率调用即可。
图片格式
原图格式以接口返回的 format 为准，下载请直接使用 url；需要 GIF 时，按 id 拼接 /images/gif/{id}.gif，不要固定原图后缀。
接口稳定性
字段只增不减，已有的名称和结构不会变更。
离线使用
直接读取 /data/memes.json 全量快照，不依赖后端服务。
