🤖 第三方 QQ Bot 只读 HTTP 接口约定

面向第三方 QQ 机器人（OneBot / Lagrange / NoneBot 等）提供稳定的只读 HTTP 接口，数据格式向后兼容。

GET /api/v1/bot/random?tag=&animated=

随机返回一张表情，支持按标签或是否动图过滤。

GET /api/v1/bot/search?q=&limit=10

关键词全文检索（支持中文、拼音、韩文原名、OCR 文本）。

GET /api/v1/bot/emotes/{id}

获取单张表情详细元数据与高清直链。

GET /api/v1/bot/tags

获取当前库内所有可用标签及表情数量。

GET /data/memes.json (纯静态托管兜底)

无需后端服务即可由 CDN / GitHub Pages 直连读取的全量静态元数据快照。
