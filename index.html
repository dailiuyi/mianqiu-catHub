把小猫接进你的机器人

五个只读接口，不用注册、不用密钥、不限次数。随机要一张，机器人马上就会卖萌。

三步就通

  1. 先摸一摸。把下面任意一个地址粘进浏览器，能看到一坨 JSON，说明小猫在线。
  2. 把图发出去。在机器人里发个 GET，拿到返回里的 data.url，当图片发就行。
  3. 让它挑得更准。想要「早八」就加 tag=早八，只要动图就加 animated=true。

小猫的五个口袋

  • GET /api/v1/bot/random

    随手抽一张。可以加 tag（标签）、series（套系）、animated（true 只要动图）收窄范围。

  • GET /api/v1/bot/search?q=&limit=10

    按关键词找。中文、拼音首字母（tt 就是贴贴）、韩文原名、图上的字都认，limit 最大 50。

  • GET /api/v1/bot/emotes/{id}

    知道 id 就查这一张的完整信息和高清直链，适合塞进自己的收藏夹。

  • GET /api/v1/bot/tags

    所有可用标签和数量，做表情菜单命令时先拉这个，菜单就不会点到空位。

  • GET /data/memes.json

    全量静态快照。后端挂了、想离线跑、或者要自己二次加工，都读它。

给 Agent 的提示词

给已有的 bot 用的话，把这两行加进它的系统提示词就够了，域名已经填好。

小猫碎碎念

要密钥吗？
不要。只读、公开、随便撸，别一秒几百次就行，小猫会累。
图是 WebP，QQ 发不出去？
同一张图还有 GIF 版：把 /images/gif/{id}.gif 拼上就能拿，id 用 random 返回的那个。
接口以后会变吗？
只会加字段，不会删也不会改已有的。安心接，不用追版本。
想让机器人按心情回不同的图？
用 search?q= 搜词就行，比如「委屈」「好耶」「摸摸头」；或者用 random?tag= 每次随机一张。
