QQ Bot 只读接口

给 OneBot、Lagrange、NoneBot 等第三方机器人用的只读 HTTP 接口，字段只增不减。

  • GET/api/v1/bot/random?tag=&animated=

    随机返回一张表情，可按标签或动静图过滤。

  • GET/api/v1/bot/search?q=&limit=10

    关键词检索，支持中文、拼音、韩文原名和图中文字。

  • GET/api/v1/bot/emotes/{id}

    单张表情的完整元数据和高清直链。

  • GET/api/v1/bot/tags

    库内全部标签及对应数量。

  • GET/data/memes.json

    全量静态快照，没有后端时 CDN 或 GitHub Pages 也能直接读。
